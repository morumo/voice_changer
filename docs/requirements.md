# 要件定義

## Goals

- マイク入力音声をリアルタイムで変換し、仮想マイクとして Discord / Google Meet / Zoom 等で利用できる
- 変換レイテンシを最小化する（目標: < 50ms）
- 完全ローカル動作（外部 API・有料サービス不使用）
- macOS / Windows 10/11 対応
- OSS として GitHub 公開できる構成にする

## Non-Goals

- クラウドや外部サービスを使った変換
- スマートフォン対応
- 録音済みファイルのバッチ変換（リアルタイム変換のみ）
- 初期バージョンでの ML ベース変換（Phase 3 以降）

### 入出力

- **入力**: システムに接続されたマイクデバイスを選択可能
- **出力**: 仮想オーディオデバイスへ出力（Discord 等はこれをマイクとして認識）
  - macOS: BlackHole 2ch
  - Windows: CABLE Input（VB-Audio Virtual Cable）
- **モニタリング**: 変換後の音声をスピーカーでリアルタイム確認できる（任意）

### カスタムプリセット

- 保存対象: ピッチ・フォルマント・ロボット・エコー各エフェクトの有効フラグとパラメータ、出力音量
- 保存先: `~/.voice_changer/presets.json`（JSON 形式）
- 操作: 新規保存 / 適用 / 上書き保存 / 削除

## 非機能要件

| 項目 | 目標値 | 備考 |
|------|--------|------|
| エンドツーエンドレイテンシ | < 50ms | 実測 ≈ 47ms（OLA ウォームアップ含む） |
| バッファサイズ | 256 samples（44100Hz 時に約 5.8ms） | `config/default.yaml` で設定 |
| 対応サンプリングレート | 44100Hz | 48000Hz は未検証 |
| 対応チャンネル数 | モノラル（変換処理）、ステレオ（出力） | |
| 波形表示フレームレート | 約 30fps | QTimer 33ms 間隔 |
| フォルマント包絡更新間隔 | 4 ホップ（≈ 23ms）に 1 回 | WORLD 分析コスト最適化 |

### レイテンシ内訳

OLA（Overlap-Add）方式の DSP エフェクトは、ブロック境界をまたいで大きな分析フレームを使う。
バッファサイズ（HOP=256）とフレームサイズ（FRAME=2048）の差分がウォームアップレイテンシとなる。

```
バッファ蓄積 (256 samples @ 44100Hz)  ≈  5.8ms
OLA ウォームアップ (FRAME - HOP = 1792 samples)  ≈ 40.6ms
出力バッファ書き込み  ≈  0.5ms
合計  ≈ 47ms
```

> 目標の 50ms 以内は達成。OLA による高品質 DSP とレイテンシのトレードオフとして受け入れる。
> ロボット・エコーのみ使用する場合は OLA ウォームアップが発生しないため ≈ 6ms。
